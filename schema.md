# Kinyoubi Campaign Data Schema

This document explains the structure of Kinyoubi_India_Campaign.json.

## Main fields

| Field | Meaning |
|---|---|
| lead_id | Unique ID of the lead |
| company_name | Name of the company |
| research | Company research information |
| sources | Sources used for research |
| score | Lead/research score |
| contact | Decision-maker/contact information |
| draft | Email draft |
| exclusions | Leads or contacts that must not be contacted |
| activity_history | Record of previous actions |
| status | Current status of the lead |
